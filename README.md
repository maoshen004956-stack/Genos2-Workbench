# Genos2 伴奏工作台

这是一个 macOS 编曲应用。选择 Yamaha Genos2 风格，输入段落和和弦，即可生成伴奏并导出分轨 MIDI、MuseScore 工程或 Guitar Pro 乐谱。

在「段落编排」上方点「乐器」，可按实际音色勾选节奏、贝斯、和弦、铺底和乐句声部。选择随歌曲草稿保存，并同时应用到试听和所有导出格式。未勾选的声部不会生成音轨。

## 1.5：iReal Pro 导入与歌曲工程

在 iReal Pro 中分享歌曲或歌单，导出 HTML 文件，然后点击工作台左下角的「导入 iReal Pro 歌曲…」（⇧⌘I），或直接把文件拖入窗口。也支持含 `irealb://` 或旧版 `irealbook://` 链接的文本。HTML 仅作为数据读取，不执行脚本。

导入预览会显示歌曲、调号、拍号、和弦和段落。歌单可逐首选择；可采用建议的 Yamaha 风格或当前风格。原谱的段落标记、单/双小节重复、反复段和第一/第二结尾会展开，形成可编辑编曲；同名段落采用相同主奏变奏。没有段落标记时保留为「主题」，不会凭空添加前奏或尾奏。缺失速度时采用所选风格原速。伴奏音色和演奏方式由 Yamaha 风格生成。

载入前会完整检查和弦；导入失败保留当前作品。复杂跳转（D.C./D.S./Coda）、中途变拍、N.C. 和引擎尚不支持的和弦会明确提示，请先在原谱中展开或调整后导入。括号备选和弦、文字说明与延长记号会提示处理方式。iReal Pro 的整曲循环次数不复制为重复段落，导入一遍完整曲式。

点左下角文件夹菜单或使用 ⌘S，可保存 `.genos2song` 工程；⌘O、拖入文件或在 Finder 中打开可恢复。工程保留歌曲名称、风格路径、调号、拍号、速度、段落、和弦与乐器选择；自定义风格需在目标电脑另行导入。当前草稿仍自动保存，导入和打开工程可通过 ⌘Z 撤销。试听时和弦、小节与段落随播放进度高亮，改变调号可整体移调。小调和弦面板使用自然小调的三和弦、七和弦及对应升降号。

## 构建

需要 macOS 14 或更新版本以及 Xcode 命令行工具。构建脚本默认使用同级目录下的 `yamaha-sx900/Genos2` 曲库，也可将曲库放在本仓库的 `Genos2/` 下，或用 `GENOS2_STYLE_LIBRARY` 指定路径。构建会把曲库打包到应用内。Git 仓库包含伴奏引擎源码和打包脚本，Yamaha 曲库与安装产物在本地管理。

```sh
./build-workbench --dmg
./arrange SkyPop-demo.txt SkyPop-demo.mid
./test-workbench-import
```

应用与 DMG 生成在项目根目录。导出 `.mscz` 时需要本机安装 MuseScore Studio。

导入回归测试覆盖链接解码、歌单、反复及结尾、和弦时值、异常输入和工程回读。可运行 `./test-workbench-import "docs/Afro Blue.html"` 额外核对本地谱例；用户提供的 HTML 不纳入代码仓库。
